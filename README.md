# CMS ART — เวอร์ชันรีดีไซน์ + แก้ช่องโหว่

## วิธีติดตั้ง
1. สำรองโปรเจกต์เดิมและฐานข้อมูลก่อน
2. คัดลอกไฟล์ในโฟลเดอร์นี้ไปทับโปรเจกต์ (รวม `assets/`, `uploads/.htaccess`)
3. **ลบ `fix_password.php` และ `reset_password.php` ออกจากเซิร์ฟเวอร์** (ไฟล์ชุดนี้ไม่มีสองไฟล์นั้นแล้ว)
4. ขึ้นเว็บจริง: ตั้งตัวแปรแวดล้อม `APP_ENV=prod`, `DB_USER`, `DB_PASS`, `DB_NAME` (อย่าใช้ root ที่ไม่มีรหัสผ่าน) และตั้งค่า `mail()`/SMTP ให้ส่งอีเมลได้
5. โฟลเดอร์ `uploads/` ต้องไม่รัน PHP — ไฟล์ `.htaccess` ที่ให้มาใช้กับ Apache; ถ้าใช้ Nginx ต้องตั้ง `location /uploads { ... }` ห้าม fastcgi เอง
6. ตารางใหม่ที่สร้างอัตโนมัติ: `login_attempts`, `password_resets` (ไม่ต้องรันอะไรเพิ่ม)

## ธีม
`style.css` (ธีมแกลเลอรี สว่าง/มืด), `theme.js` (จำธีมที่ผู้ใช้เลือก), `admin.css` (หน้าแอดมิน)
